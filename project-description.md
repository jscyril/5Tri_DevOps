# Project Description

This repository contains the project developed as part of the 5th Trimester MCA DevOps work.

The project is maintained collaboratively using Git and GitHub, with separate branches for individual contributions and pull requests used to merge changes into the main branch.

## Project Files

- index.html - Main web page
- styles.css - Styling for the web application
- script.js - JavaScript functionality
- README.md - Repository information

## Purpose

The project is used to practice collaborative development, Git branching, commits, pushes, pull requests, and merging changes using GitHub.
